# Wasserstein Distance (aka Earth mover's distance) in C# Generic Maths
Moving dirt, no matter what the number type

# Pre-requisites

* git
* .NET 10 or higher

# Getting started

```bash
# clone repo
git clone https://github.com/TrevorDArcyEvans/Wasserstein.git

# build
cd Wasserstein
dotnet build

# run demo
dotnet run

# demo output
Wasserstein(P, Q1) = 1.0000
Wasserstein(P, Q2) = 2.0000
```

# Background

Wasserstein distance is just one of a number of methods for comparing two histograms for similarity.
